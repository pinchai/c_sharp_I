# Student Assignment: Object-Oriented Programming (OOP)

## Topic: Fundamental Concepts of Object-Oriented Programming

### Learning Topics

1. **Introduction to OOP** – Explain the concept, purpose, and advantages of Object-Oriented Programming.
2. **Class vs. Object** – Describe the differences between a class and an object with practical examples.
3. **Fields vs. Properties** – Explain the differences between fields and properties and demonstrate their usage.
4. **Methods** – Explain methods, parameters, return values, and how methods perform operations.
5. **Constructors** – Describe the purpose of constructors and explain how they initialize objects.
6. **Encapsulation** – Explain data hiding, access modifiers, and how encapsulation protects data.
7. **Inheritance** – Explain how inheritance enables a class to reuse and extend the functionality of another class.

### Student Requirements

- Define and explain each concept in your own words.
- Provide at least one programming example for each topic.
- Demonstrate the concepts using a practical programming language, such as C#.
- Explain the expected output of each example.
- Develop a small program that combines the concepts of OOP.

### Practical Project

**Title:** Design and Development of a Student Management System Using Object-Oriented Programming

The program should demonstrate classes, objects, fields, properties, methods, constructors, encapsulation, and inheritance.

### Deliverables

1. Documentation explaining each OOP concept.
2. Screenshots of the program output.
3. A video presentation and demonstration of the project.
